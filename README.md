# ThermoRoute 2.0

Premium 3D climate-tech dashboard for route intelligence and urban thermal exposure.

## Stack

- React 18
- TypeScript
- Vite
- TailwindCSS
- Zustand
- Three.js / React Three Fiber

## Setup

```bash
npm install
npm run dev
```

## API contract

This front-end intentionally consumes the existing backend at `/api/optimize` without modifying the backend contract.

## Notes

- Backend and Flutter app remain untouched.
- This repository is a new web front-end layer for the 3D dashboard.
